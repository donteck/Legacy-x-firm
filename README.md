# Legacy X Firm

Official WordPress website repository for Legacy X Firm.

## Canonical Website Version

The current and approved production design is the **Legacy X Firm Luxury Private Advisory** build.

Approved baseline branch: `best/luxury-home-approved-2026-09-02`

The standalone production theme is:

`wp-content/themes/legacy-x-firm/`

This is the only website design that should be treated as current. Previous Consultio-based and earlier homepage concepts are deprecated and must not be restored or reused unless explicitly requested by the owner.

## Architecture Direction

The platform is being rebuilt as a lightweight custom WordPress system for business owners, executives, investors, real-estate principals, family enterprises, and private clients.

Core direction: Strategy • Capital • Legacy

## Deployment

Production deployment is automated through GitHub Actions to the Hestia-hosted WordPress installation.

Do not commit credentials, private client data, database dumps, uploads, backups, or server secrets to this public repository.
